# Contributor Code of Conduct

## Our commitment

This repository welcomes respectful participation from learners, developers, reviewers, and contributors of all experience levels. We aim to provide a professional and inclusive environment for discussing data engineering practices and improvements.

## Expected behavior

- Communicate respectfully and offer constructive, specific feedback.
- Acknowledge differences in experience, technical approaches, and perspectives.
- Protect personal, proprietary, or otherwise confidential information.
- Document data assumptions, limitations, and whether data is synthetic or public.
- Help keep contributions reproducible, understandable, and responsibly tested.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, personal attacks, disclosure of others' private information without permission, or use of this project to facilitate unauthorized data access are not tolerated.

## Reporting and enforcement

Report conduct concerns privately to the repository maintainer using an available private contact channel. Do not post personal data or sensitive reports in public issues. The maintainer may remove harmful content, close discussions, or restrict participation when necessary. No specific response time is guaranteed.

## Scope

These standards apply to project-related issues, pull requests, reviews, discussions, and other repository community spaces.
